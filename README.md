# AI活用度診断（Abierto Works）

12問・約2分で、**個人での**AIの使い方を100点満点で採点し、日本（15歳以上）で上位何%か、レベル別に「AIでできること」と「次の一歩」を表示する診断ページです。
AIを学んでいる人と学びたい人をつなぐコミュニティ（LINEオープンチャット）への入口も兼ねています。

- `index.html` 1枚で完結（HTML・CSS・JavaScriptを内包）。ビルド不要
- 回答はブラウザ内だけで計算し、どこにも送信・保存しません
- GitHub Pagesでそのまま公開できます

## 公開手順（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** を「Deploy from a branch」にする
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 1〜2分後、`https://abiertoworks-boop.github.io/ai-shindan/` で公開されます

## LINEオープンチャットのURLを入れる

`index.html` の下の方、`<script>` 内の次の行に招待URLを入れて保存（コミット）してください。

```js
const LINE_URL = "";
```

空のままだと、ボタンは「LINEオープンチャット（近日公開）」と表示され、押せない状態になります。

## 診断の設計

- **基準**：会社支給のAIを業務で使うだけの場合は含めず、「会社で使われているAIの仕組みを、個人でも自分で用意して使えているか」で答える
- **5つの軸**：頻度／伝える力／見極める力／任せる力／つくる力（AI Fluencyフレームワークの「任せる・伝える・見極める・責任をもつ」を参考）
- **会社の仕組みの個人版（9項目）**：有料AI契約、自分専用AI、議事録AI、資料検索AI、自動処理、定期実行、AIエージェント、サイト・アプリ公開、AI利用の自分ルール
- **レベル**：Lv0 未接触 〜 Lv8 フロンティアの9段階。各レベルで「できること」「次の一歩」「つまずきと抜け方」「次に上がると何ができるか」を表示
- 最終問（コミュニティでの関わり方）は採点に含めず、自己紹介文の生成に使います

## 「上位◯%」の根拠

| 境界 | 割合 | 根拠 |
|---|---|---|
| 生成AIを使ったことがある | 58.8% | 総務省『令和8年版 情報通信白書』2025年度個人向け調査 |
| ほぼ毎日使う | 約17.6% | 同白書「ほぼ毎日 約3割」を利用者内比率とみなした換算（推定） |
| コード生成AIの利用経験 | 7.0% | 同白書 サービス種類別 |
| 自動化・エージェント自作 | 約2% | 推定（公的統計なし） |
| 本番運用・複数エージェント | 約0.5% | 推定（公的統計なし） |
| 評価・安全性・製品化 | 約0.1% | 推定（公的統計なし） |

上位7%より上は公的統計がないため、結果は「上位0.5〜2%（推定）」のように幅で表示します。
配点・境界値はAbierto Worksが設計したもので、統計的に検証された尺度ではありません。白書が更新されたら、`index.html` 内の `A`（境界）と根拠表を更新してください。

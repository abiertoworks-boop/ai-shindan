# AI EVOLUTION 診断システム

12問の回答から AI 活用レベルを診断し、回答と結果を Google スプレッドシートへ保存する Google Apps Script ウェブアプリです。画面は `Index.html`、採点・保存処理は `Code.gs` にあります。GitHub Pages では動作しません。

## ファイル

- `Code.gs` — 診断、採点、保存先シートの準備
- `Index.html` — スマートフォン対応の診断画面
- `appsscript.json` — Apps Script の実行環境設定

## セットアップと公開

1. 回答を保存する Google スプレッドシートを作成または選びます。回答データを閲覧できるユーザーを確認し、シート自体は必要な運用担当者だけに共有してください。
2. スプレッドシートの **拡張機能 → Apps Script** を開きます。
3. エディタで `Code.gs` の内容をプロジェクトの `Code.gs` に貼り付けます。HTML ファイルを追加し、名前を `Index` にして `Index.html` の内容を貼り付けます。
4. プロジェクト設定で「`appsscript.json` マニフェスト ファイルをエディタで表示する」を有効にし、このリポジトリの `appsscript.json` の内容を反映します。
5. 保存し、関数一覧から `setupDiagnosisSheet` を実行します。Google の権限確認を許可してください。この実行で現在のスプレッドシート ID が Apps Script のスクリプトプロパティに記録され、`AI診断回答` タブが準備されます。既存タブ・既存データは削除しません。
6. **デプロイ → 新しいデプロイ → ウェブアプリ** を選びます。実行ユーザーは通常「自分」、アクセスできるユーザーは対象者に合わせて選択します。
7. 組織内のみなら組織内に限定します。不特定多数に公開する場合は「全員」などの設定を選びます。Google Workspace 管理者の制限により選択できないことがあります。
8. デプロイ後に発行されたウェブアプリ URL を開いて動作を確認し、利用者へ案内します。コードを更新した場合は、デプロイの管理から新しいバージョンを反映してください。

回答はウェブアプリの所有者権限で指定スプレッドシートへ追記されます。一般公開では第三者による送信や大量投稿の可能性があります。公開範囲を必要最小限にし、シートの共有設定・回答件数を運用中も確認してください。この初期版にはログイン認証、投稿レート制限、CAPTCHA はありません。

## GitHub から同期する場合（任意）

手動コピーの代わりに `clasp` を使う場合は、Google Apps Script API を有効にしてから、ローカルで `clasp login` と `clasp clone <Apps Script のスクリプトID>` を実行します。このリポジトリをローカルプロジェクトのルートとして使い、`clasp push` で反映します。`.clasp.json` はスクリプト ID を含むため、このリポジトリには追加しないでください。ウェブアプリのデプロイ操作は Apps Script 側で行います。

## データとプライバシー

- 保存項目は回答日時、任意の名前、職業・業種・役職・企業規模・年代、合計点・レベル・タイプ・4領域の点数、12問の回答です。
- 名前は任意です。診断ページで案内しているとおり、機密情報や顧客の個人情報を入力させないでください。
- 公開前に、運営主体、利用目的、保存先、保存期間、問い合わせ先、削除依頼の方法を実際の運用に合わせて利用者へ明示してください。回答データの管理・削除は運営者が行います。
- スプレッドシート ID や認証情報をソースコードへ書き込まないでください。保存先は初回セットアップ時にスクリプトプロパティへ記録します。

## 診断について

- 12問を各0〜4点で採点し、重み付けして100点満点に換算します。
- 能力領域は基礎力20点、ビジネス実装力30点、自動化・エージェント力30点、技術・先端活用力20点です。
- 8段階のレベルは合計点に加えて上位レベルごとの実践条件で判定します。8タイプは関連設問の点数で決まり、同点の場合は最大2タイプを表示します。
- 全国代表標本に基づく調査ではないため、日本人全体の上位何％という順位は表示しません。質問、配点、境界値は運用データで検証してください。
